The warning is expected

Android flags anything installed outside the Play Store. On that prompt, tap Settings, allow your browser to install apps, then open the file again. Company apps are distributed this way.

Good to know

Updating later

Once installed, BamForm checks this page’s release manifest for itself and offers the update in the app. It verifies the published checksum and that the file carries the same signing key before Android’s installer is ever opened — you still confirm the install.

Installing over the existing app keeps everything on the device. Uninstalling first does not — any records still waiting to sync are lost with it.

Using a different server

The app connects to form.bevorasg.com as shipped. To point it elsewhere, expand Server at the foot of the sign-in screen and enter the address — the app checks the server answers before it switches.

Records still waiting to sync stay with the server they were captured on. Finish syncing before moving a device.

iPhone and iPad

There is no app file for iOS, and none is needed. Open form.bevorasg.com in Safari, tap Share, then Add to Home Screen.

It installs to the home screen and works the same way, offline included.
