# Slice 23-PDFA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a record is archived, render its PDF once, convert it to PDF/A, hash the bytes and store them — so the controlled copy an auditor downloads is a fixed, provable artefact instead of a fresh render from the current template.

**Architecture:** A new `record_document` table holds one *current* copy per record plus retained superseded revisions. Freezing runs on the worker (BullMQ job name `freeze`), enqueued **after** the archiving transaction commits, in the same `.then()` seam `verification.service.ts` already uses for side effects. Ghostscript converts Chromium's output to PDF/A; veraPDF measures the level actually achieved in CI. `PdfCoordinatorService` serves stored bytes when a current row exists and falls back to today's on-demand render otherwise.

**Tech Stack:** NestJS 10, Prisma, PostgreSQL 16, BullMQ/Redis, MinIO, Puppeteer + system Chromium, Ghostscript (new), veraPDF (CI only), Jest.

The only column that may ever change is `superseded_at`.

```prisma
  supersededAt     DateTime?                 @map("superseded_at") @db.Timestamptz(6)

  job Job @relation(fields: [jobId], references: [id])

  @@index([jobId, supersededAt])
```

- [ ] **Step 4: Write the migration**

```sql
-- api/prisma/migrations/20260729010000_record_document/migration.sql
--
-- Slice 23-PDFA — the frozen controlled copy.
--
-- IMMUTABILITY IS ENFORCED HERE, NOT IN APPLICATION CODE. `grants.sql` runs
-- `GRANT SELECT, INSERT, UPDATE ON ALL TABLES` after every migration, so
-- `bamform_app` holds UPDATE on this table whether or not anyone intended it.
-- Without the trigger below, one stray `prisma.recordDocument.update()` could
-- rewrite a digest and silently destroy the only property this table exists
-- to provide. The single legal mutation is stamping `superseded_at`.

CREATE TYPE record_document_provenance_t AS ENUM (
  'FROZEN_AT_ARCHIVE', 'BACKFILLED', 'VOID_ANNOTATED'
);

CREATE TABLE record_document (
  id                uuid PRIMARY KEY DEFAULT uuidv7(),
  job_id            uuid NOT NULL REFERENCES job(id),
  revision          integer NOT NULL,
  storage_key       text NOT NULL,
  sha256            bytea NOT NULL,
  byte_size         integer NOT NULL,
  conformance_level text NOT NULL,
  provenance        record_document_provenance_t NOT NULL,
  rendered_at       timestamptz(6) NOT NULL,
  superseded_at     timestamptz(6),
  CONSTRAINT record_document_job_revision_key UNIQUE (job_id, revision),
  CONSTRAINT record_document_sha256_len CHECK (octet_length(sha256) = 32),
  CONSTRAINT record_document_byte_size_positive CHECK (byte_size > 0)
);

-- At most ONE current copy per record, enforced by the database rather than
-- by careful application code.
CREATE UNIQUE INDEX record_document_one_current
  ON record_document (job_id) WHERE superseded_at IS NULL;

CREATE INDEX record_document_job_superseded_idx
  ON record_document (job_id, superseded_at);

CREATE OR REPLACE FUNCTION record_document_immutable()
RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
  IF NEW.id IS DISTINCT FROM OLD.id
     OR NEW.job_id IS DISTINCT FROM OLD.job_id
     OR NEW.revision IS DISTINCT FROM OLD.revision
     OR NEW.storage_key IS DISTINCT FROM OLD.storage_key
     OR NEW.sha256 IS DISTINCT FROM OLD.sha256
     OR NEW.byte_size IS DISTINCT FROM OLD.byte_size
     OR NEW.conformance_level IS DISTINCT FROM OLD.conformance_level
     OR NEW.provenance IS DISTINCT FROM OLD.provenance
     OR NEW.rendered_at IS DISTINCT FROM OLD.rendered_at
  THEN
    RAISE EXCEPTION
      'record_document is immutable except superseded_at (attempted on id %)', OLD.id
      USING ERRCODE = 'check_violation';
  END IF;
  RETURN NEW;
END;
$$;

CREATE TRIGGER record_document_immutable_trg
  BEFORE UPDATE ON record_document
  FOR EACH ROW EXECUTE FUNCTION record_document_immutable();
```

```typescript
// api/src/pdf/pdfa-converter.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { execFile } from 'node:child_process';
import { mkdtemp, readFile, rm, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { promisify } from 'node:util';

const execFileAsync = promisify(execFile);

/** Ghostscript can hang on malformed input; the worker must not. */
const CONVERSION_TIMEOUT_MS = 60_000;

/**
 * PDF/A output intent definition. PDF/A REQUIRES an output intent with an ICC
 * profile; Ghostscript ships sRGB and this pdfmark block references it.
 */
export const PDFA_DEF_PS = `%!
[ /Title (BamForm controlled record) /DOCINFO pdfmark
[/_objdef {icc_PDFA} /type /stream /OBJ pdfmark
[{icc_PDFA} <</N 3>> /PUT pdfmark
[{icc_PDFA} (sRGB.icc) (r) file /PUT pdfmark
[/_objdef {OutputIntent_PDFA} /type /dict /OBJ pdfmark
[{OutputIntent_PDFA} <<
  /Type /OutputIntent /S /GTS_PDFA1
  /OutputConditionIdentifier (sRGB)
  /DestOutputProfile {icc_PDFA}
>> /PUT pdfmark
[{Catalog} <</OutputIntents [{OutputIntent_PDFA}]>> /PUT pdfmark
`;

export function buildGhostscriptArgs(input: string, output: string, defPs: string): string[] {
  return [
    '-dPDFA=2',
    // FAIL rather than emit something non-conformant we would then mislabel.
    '-dPDFACompatibilityPolicy=1',
    '-dBATCH',
    '-dNOPAUSE',
    '-dSAFER',
    '-dNOOUTERSAVE',
    '-sColorConversionStrategy=UseDeviceIndependentColor',
    '-sDEVICE=pdfwrite',
    `-sOutputFile=${output}`,
    defPs,
    input,
  ];
}

@Injectable()
export class PdfaConverterService {
  private readonly logger = new Logger(PdfaConverterService.name);

  /**
   * Convert Chromium's plain PDF to PDF/A.
   *
   * NEVER throws. A conversion failure returns the ORIGINAL bytes with
   * `converted: false` — an auditor losing access to a signed record because
   * an archival-formatting step failed would be a far worse outcome than a
   * record stored as a plain PDF and labelled as such.
   */
  async toPdfA(pdf: Buffer): Promise<PdfaConversionResult> {
    const dir = await mkdtemp(join(tmpdir(), 'bamform-pdfa-'));
    const input = join(dir, 'in.pdf');
    const output = join(dir, 'out.pdf');
    const defPs = join(dir, 'PDFA_def.ps');
    try {
      await writeFile(input, pdf);
      await writeFile(defPs, PDFA_DEF_PS, 'utf8');
      await execFileAsync('gs', buildGhostscriptArgs(input, output, defPs), {
        timeout: CONVERSION_TIMEOUT_MS,
        maxBuffer: 8 * 1024 * 1024,
      });
      const converted = await readFile(output);
      if (converted.length === 0) {
        throw new Error('Ghostscript produced an empty file');
      }
      return { pdf: converted, converted: true };
    } catch (error) {
      const reason = (error as Error).message;
      this.logger.error(`PDF/A conversion failed, storing the plain render instead: ${reason}`);
      return { pdf, converted: false, reason };
    } finally {
      await rm(dir, { recursive: true, force: true }).catch(() => undefined);
    }
  }
}

export interface PdfaConversionResult {
  pdf: Buffer;
  converted: boolean;
  reason?: string;
}
```

```typescript
import type { RecordDocument, RecordDocumentProvenanceT } from '@prisma/client';
import { PrismaService } from '../prisma/prisma.service';

export interface NewRecordDocument {
  jobId: string;
  revision: number;
  storageKey: string;
  sha256: Buffer;
  byteSize: number;
  conformanceLevel: string;
  provenance: RecordDocumentProvenanceT;
  renderedAt: Date;
}

@Injectable()
export class RecordDocumentRepository {
  constructor(private readonly prisma: PrismaService) {}

  findCurrent(jobId: string): Promise<RecordDocument | null> {
    return this.prisma.recordDocument.findFirst({ where: { jobId, supersededAt: null } });
  }

  async nextRevision(jobId: string): Promise<number> {
    const latest = await this.prisma.recordDocument.findFirst({
      where: { jobId }, orderBy: { revision: 'desc' }, select: { revision: true },
    });
    return (latest?.revision ?? 0) + 1;
  }

  async supersedeCurrent(jobId: string): Promise<void> {
    // Only `supersededAt` may change — the migration's trigger enforces it.
    await this.prisma.recordDocument.updateMany({
      where: { jobId, supersededAt: null },
      data: { supersededAt: new Date() },
    });
  }

  insert(row: NewRecordDocument): Promise<RecordDocument> {
    return this.prisma.recordDocument.create({ data: row });
  }

  /** ARCHIVED/VOIDED records with no current document — the sweep's work-list (Task 7). */
  findRecordsMissingCurrentDocument(limit: number): Promise<{ id: string; status: string }[]> {
    return this.prisma.$queryRaw`
      SELECT j.id::text AS id, j.status::text AS status
      FROM job j
      LEFT JOIN record_document d ON d.job_id = j.id AND d.superseded_at IS NULL
      WHERE j.status IN ('ARCHIVED', 'VOIDED') AND d.id IS NULL
      ORDER BY j.id
      LIMIT ${limit}`;
  }
}
```

```typescript
// api/src/pdf/record-document.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { createHash } from 'node:crypto';
import type { RecordDocumentProvenanceT } from '@prisma/client';
import { MinioService } from '../storage/minio.service';
import { PdfRenderService } from './pdf-render.service';
import { PdfaConverterService } from './pdfa-converter.service';
import { RecordDocumentRepository } from './record-document.repository';

export function storageKeyFor(recordId: string, revision: number): string {
  return `records/${recordId}/v${revision}.pdf`;
}

export interface FrozenDocument {
  storageKey: string;
  sha256: Buffer;
  byteSize: number;
  revision: number;
}

@Injectable()
export class RecordDocumentService {
  private readonly logger = new Logger(RecordDocumentService.name);

  constructor(
    private readonly renderer: PdfRenderService,
    private readonly converter: PdfaConverterService,
    private readonly minio: MinioService,
    private readonly repo: RecordDocumentRepository,
  ) {}

  async freeze(
    recordId: string,
    provenance: RecordDocumentProvenanceT,
  ): Promise<FrozenDocument> {
    const plain = await this.renderer.renderRecordPdf(recordId);
    const conversion = await this.converter.toPdfA(plain);

    // The level is MEASURED in CI by veraPDF, never asserted here. Until a
    // validator has spoken, the only honest values are 'NONE' (conversion did
    // not run) and 'PDF/A-2' (it did, level unmeasured at runtime).
    const conformanceLevel = conversion.converted ? 'PDF/A-2' : 'NONE';

    const bytes = conversion.pdf;
    const revision = await this.repo.nextRevision(recordId);
    const storageKey = storageKeyFor(recordId, revision);

    await this.minio.putObject(storageKey, bytes, 'application/pdf');

    // Supersede BEFORE insert: `record_document_one_current` is a partial
    // unique index, so inserting first would violate it.
    await this.repo.supersedeCurrent(recordId);

    const sha256 = createHash('sha256').update(bytes).digest();
    await this.repo.insert({
      jobId: recordId,
      revision,
      storageKey,
      sha256,
      byteSize: bytes.length,
      conformanceLevel,
      provenance,
      renderedAt: new Date(),
    });

    this.logger.log(
      `froze record ${recordId} rev ${revision} (${bytes.length} bytes, ` +
        `${conformanceLevel}, ${provenance})`,
    );
    return { storageKey, sha256, byteSize: bytes.length, revision };
  }
}
```

```typescript
import type { Readable } from 'node:stream';

async function bufferFromStream(stream: Readable): Promise<Buffer> {
  const chunks: Buffer[] = [];
  for await (const chunk of stream) {
    chunks.push(Buffer.isBuffer(chunk) ? chunk : Buffer.from(chunk as string));
  }
  return Buffer.concat(chunks);
}
```

```typescript
// api/src/pdf/record-document-sweep.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { PdfQueueService } from './pdf-queue.service';
import { RecordDocumentRepository } from './record-document.repository';

/** Bounded so one sweep cannot flood the queue on a large backlog (e.g. right after the backfill lands). */
const SWEEP_BATCH = 50;

@Injectable()
export class RecordDocumentSweepService {
  private readonly logger = new Logger(RecordDocumentSweepService.name);

  constructor(
    private readonly repo: RecordDocumentRepository,
    private readonly queue: PdfQueueService,
  ) {}

  async run(): Promise<{ found: number; enqueued: number }> {
    const missing = await this.repo.findRecordsMissingCurrentDocument(SWEEP_BATCH);
    let enqueued = 0;
    for (const record of missing) {
      try {
        await this.queue.enqueueFreeze({
          recordId: record.id,
          provenance: record.status === 'VOIDED' ? 'VOID_ANNOTATED' : 'FROZEN_AT_ARCHIVE',
        });
        enqueued += 1;
      } catch (error) {
        this.logger.error(`sweep could not enqueue ${record.id}: ${(error as Error).message}`);
      }
    }
    if (missing.length > 0) {
      this.logger.log(`record-document sweep: found=${missing.length} enqueued=${enqueued}`);
    }
    return { found: missing.length, enqueued };
  }
}
```

```typescript
// api/src/pdf/backfill-record-documents.ts
import { Logger } from '@nestjs/common';

export interface BackfillDeps {
  findMissing(limit: number): Promise<{ id: string; status: string }[]>;
  freeze(recordId: string, provenance: 'BACKFILLED'): Promise<unknown>;
}

export interface BackfillResult { scanned: number; frozen: number; failed: number }

/**
 * Reconstructs a controlled copy for records archived before slice 23-PDFA.
 *
 * These are RECONSTRUCTIONS, not originals: they are rendered from TODAY's
 * template because the bytes as they were at signing were never stored. They
 * are stamped BACKFILLED with the backfill date so an auditor can always tell
 * the two apart. Do not change that stamp to make the archive look tidier.
 *
 * Run out-of-band, not as a migration step: it needs Chromium and Ghostscript
 * per record and must be observable and resumable.
 */
export async function runBackfill(
  deps: BackfillDeps,
  opts: { batchSize: number; dryRun: boolean },
): Promise<BackfillResult> {
  const logger = new Logger('BackfillRecordDocuments');
  const result: BackfillResult = { scanned: 0, frozen: 0, failed: 0 };

  for (;;) {
    const batch = await deps.findMissing(opts.batchSize);
    if (batch.length === 0) break;
    result.scanned += batch.length;

    if (opts.dryRun) {
      logger.log(`[dry-run] would backfill ${batch.length}: ${batch.map((r) => r.id).join(', ')}`);
      break;   // no writes, so the work-list never shrinks — one pass only
    }

    for (const record of batch) {
      try {
        await deps.freeze(record.id, 'BACKFILLED');
        result.frozen += 1;
        logger.log(`backfilled ${record.id} (${result.frozen} done)`);
      } catch (error) {
        result.failed += 1;
        logger.error(`backfill FAILED for ${record.id}: ${(error as Error).message}`);
      }
    }
    // A batch where every record failed would loop forever on the same rows.
    if (result.failed > 0 && result.frozen === 0) break;
  }

  logger.log(`backfill complete: ${JSON.stringify(result)}`);
  return result;
}
```

Then the entrypoint, in the same file. `BackfillDeps` is deliberately a narrow adapter interface rather than the repository type — that is what keeps `runBackfill` unit-testable without a Nest container:

```typescript
  void (async () => {
    const { NestFactory } = await import('@nestjs/core');

    } finally {

    }
  })();
}
```
